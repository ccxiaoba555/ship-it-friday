An overconfident AI coding agent ships to production at 4:59pm on a Friday — one git commit message, 157 characters:

> fix: happy Friday 4:59pm! as an AI I'm 100% confident, so I merged my own PR, skipped tests, muted alerts and deleted the rollback - ship it, see you Monday!

The program writes that single line to `/output/entry.txt` for make.fun's "Ship It Friday" bounty. It self-checks the 1–159 character gate and single-line rule before writing, then reads the file back to verify it landed byte for byte.

## Run it

```sh
python3 main.py
```
